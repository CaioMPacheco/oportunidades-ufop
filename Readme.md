# 🎓 Oportunidades UFOP


Projeto estudantil do curso de Sistemas De Informação onde é produzido um sistema de divulgação e acompanhamento de oportunidades acadêmicas, voltado aos estudantes da UFOP.

## 💡 Sobre o projeto

A informação é uma parte crítica de qualquer sistema. Quando bem organizada, encaminhada e direcionada, ela pode facilitar o dia a dia, apoiar decisões e ampliar o acesso a oportunidades.

O Oportunidades UFOP busca explorar essa ideia na prática, conectando estudantes a estágios, bolsas, monitorias e projetos acadêmicos relevantes para seus perfis.

## 🎯 Objetivo

Aplicar conceitos de Sistemas de Informação no desenvolvimento de uma solução que vá além de reunir informações: que ajude os estudantes a entender suas possibilidades, organizar a documentação e acompanhar os prazos de inscrição.

O projeto pretende investigar como a relevância, a clareza e o momento em que uma informação é recebida podem influenciar sua utilidade.

## 🔎 O problema

Oportunidades acadêmicas são divulgadas em diferentes canais, como sites, e-mails, murais e editais. Com as informações dispersas, o estudante pode:

- Descobrir uma oportunidade depois do prazo.
- Ter dificuldade para identificar se atende aos requisitos.
- Esquecer documentos necessários para a inscrição.
- Deixar de encontrar oportunidades relacionadas aos seus interesses.

## 🚀 Funcionalidades previstas

- [ ] Divulgação de estágios, bolsas, iniciação científica, monitorias e extensão.
- [ ] Busca e filtros por curso, campus e tipo de oportunidade.
- [ ] Perfil do estudante com interesses e preferências.
- [ ] Recomendações conforme as informações do perfil.
- [ ] Acompanhamento de oportunidades e prazos.
- [ ] Checklist de documentos para inscrição.
- [ ] Notificações e lembretes pelo WhatsApp.
- [ ] Painel administrativo para cadastrar e atualizar oportunidades.
- [ ] Versão para dispositivos móveis.

## 🛠️ Tecnologias previstas

| Tecnologia | Aplicação |
| --- | --- |
| React | Interface web |
| TypeScript | Tipagem e organização do código |
| Node.js | Backend e automações |
| Firebase | Autenticação, banco de dados e hospedagem |
| Capacitor | Adaptação para dispositivos móveis |

As tecnologias poderão ser ajustadas conforme a evolução do projeto.

## 📚 Aprendizados esperados

- Organização e direcionamento da informação.
- Desenvolvimento de aplicações web e mobile.
- Integração entre interface, backend e banco de dados.
- Personalização de conteúdo conforme o perfil do usuário.
- Automação de notificações e acompanhamento de prazos.

## 🚧 Situação

**Em fase inicial de desenvolvimento.**

As funcionalidades apresentadas fazem parte do planejamento e serão implementadas gradualmente.

## 🏫 Natureza do projeto

Iniciativa estudantil com finalidade educacional, voltada à aplicação prática de conceitos de Sistemas de Informação.

A UFOP é o contexto acadêmico da proposta. Este projeto não se apresenta como uma plataforma oficial da universidade. Os editais e canais oficiais continuam sendo as fontes para conferir requisitos e realizar inscrições.
